Camera preview shows but the badge above doesn't flip to LIVE after ~15 seconds? Check your internet upload speed and that nothing else (another tab, OBS) is already using this stream key.

Advanced: use broadcast software (OBS, Streamlabs) instead

Open OBS (or Streamlabs, etc.) → Settings → Stream → choose "Custom", paste the RTMP URL as the server and the Stream Key above, then click Start Streaming in that software. Don't use this at the same time as the camera button above. Stop one before starting the other.

Want multiple camera angles? Set up scenes/sources in OBS (or vMix) with your cameras, and switch between them there. Whatever you're showing in your broadcast software is exactly what goes out over this same stream key. There's nothing extra to configure on GospelGoLive's side.

Simulcast to YouTube & Facebook

Enter your own YouTube/Facebook live stream RTMP URL and stream key. When you go live here, we'll also send your broadcast to these. Requires Mux's Simulcast Targets add on to be enabled on this account's Mux plan.
